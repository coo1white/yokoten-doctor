# Security

## Report a problem in this page or its server

Use GitHub's private report: open the **Security** tab of this repo and click **Report a vulnerability**. Please do not open a public issue for it.

Examples:

- The sandbox runs a scanned repo's code, or keeps its network after the copy.
- A key reaches the repo, the browser, the sandbox, a model prompt or a log.
- A repo's text reaches the page as HTML.
- Code can reach Solana mainnet, or move coins.

We answer within 7 days.

## A real security risk in a review report

A review report is public, and it can name a real weakness in someone's repo. If you see one in a report about your repo, report it to us the same way. We will take that report down while you fix it.

If you see one in a report about someone else's repo, tell that repo's maintainers first, through their own security policy.

## Wrong check results

A wrong file check comes from yokoten, so report it in the [yokoten repo](https://github.com/yokoten-labs/yokoten). A wrong risk in a review report is not a security problem. Open a normal issue here.
